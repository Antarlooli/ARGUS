# Changelog

## 0.1.0 — Initial
- Multi-column dashboard with persistent RSS, 4chan, and Bluesky columns.
- Bluesky app-password login, home timeline, and hashtag search.
- Local RSS/Atom/RDF/JSON Feed parsing.
- 4chan board picker, rate-limited catalog/thread API, quote navigation, hover zoom, and lightbox.
- Sanitized remote post markup and runtime host permission for custom RSS outlets.
- Bluesky request pacing, automatic access-token refresh, and serialized token persistence.
- Per-column retry actions, empty states, stale-request protection, and connected-account removal.
